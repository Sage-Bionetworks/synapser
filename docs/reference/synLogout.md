# synLogout

Removes authentication information from the Synapse client.

## Usage

``` r
synLogout(forgetMe=FALSE)
```

## Arguments

- forgetMe:

  Set as TRUE to clear any local storage of authentication
  information.  
  See the flag "rememberMe" in synLogin.

## Examples

``` r
if (FALSE) { # \dontrun{
synLogout()
} # }
```
