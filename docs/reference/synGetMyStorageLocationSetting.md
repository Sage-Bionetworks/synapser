# synGetMyStorageLocationSetting

Get a StorageLocationSetting by its id.

## Usage

``` r
synGetMyStorageLocationSetting(storage_location_id)
```

## Arguments

- storage_location_id:

  id of the StorageLocationSetting to retrieve.  
  The corresponding StorageLocationSetting must have been created by
  this user.

## Value

the StorageLocationSetting
