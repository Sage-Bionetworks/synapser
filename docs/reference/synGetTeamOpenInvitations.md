# synGetTeamOpenInvitations

Retrieve the open requests submitted to a
[Team](https://rest-docs.synapse.org/rest/GET/team/id/openInvitation.html)

## Usage

``` r
synGetTeamOpenInvitations(team)
```

## Arguments

- team:

  A Team object or a team's ID.

## Value

Generator of MembershipRequest dictionaries
