# synGetTeam

Finds a team with a given ID or name.

## Usage

``` r
synGetTeam(id)
```

## Arguments

- id:

  The ID or name of the team or a Team object to retrieve

## Value

An object of type Team

## Examples

``` r
if (FALSE) { # \dontrun{
# By ID
synGetTeam(teamId)

# By Name
synGetTeam("my_team_name")
} # }
```
