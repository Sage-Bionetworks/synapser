# synPrintEntity

Pretty prints an Entity.

## Usage

``` r
synPrintEntity(entity, ensure_ascii=TRUE)
```

## Arguments

- entity:

  The entity to be printed.  

- ensure_ascii:

  If TRUE, escapes all non-ASCII characters

## Examples

``` r
if (FALSE) { # \dontrun{
synPrintEntity("syn123")
} # }
```
