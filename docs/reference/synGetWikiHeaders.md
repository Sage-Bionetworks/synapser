# synGetWikiHeaders

Retrieves the headers of all Wikis belonging to the owner (the entity to
which the Wiki is attached).

## Usage

``` r
synGetWikiHeaders(owner)
```

## Arguments

- owner:

  An Entity

## Value

A list of Objects with three fields: id, title and parentId.

## Examples

``` r
if (FALSE) { # \dontrun{
synGetWikiHeaders(project)
} # }
```
