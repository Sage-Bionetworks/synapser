# synOnweb

Opens up a browser window to the entity page or wiki-subpage.

## Usage

``` r
synOnweb(entity, subpageId=NULL)
```

## Arguments

- entity:

  Either an Entity or a Synapse ID  

- subpageId:

  (Optional) ID of one of the wiki's sub-pages

## Examples

``` r
if (FALSE) { # \dontrun{
synOnweb("syn123")
} # }
```
